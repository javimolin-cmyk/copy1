Web → GitHub Cloner 2

Captura una web como navegador real mediante Chromium, incluyendo contenido cargado por JavaScript y recursos solicitados durante la navegación.

1 · Capturar

Esta herramienta captura contenido públicamente accesible. No intenta eludir inicio de sesión, suscripciones, paywalls, DRM, controles de acceso ni contenido privado. Si una parte de una web sólo aparece después de autenticar una cuenta o pagar una suscripción, esa barrera no se elimina.

2 · GitHub

El token se usa localmente para publicar el resultado y no se escribe en el repositorio.
